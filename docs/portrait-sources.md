# Reference portrait sources

These URLs were preserved from the retired one-time portrait download scripts. They record the original download locations, not an independent spoiler or identity audit. The deployed WebP files are committed in `assets/`; routine recap work does not require downloading them again.

For replacements, download only the needed source into a temporary directory, inspect it and its reveal stage, and use `tools/optimize_images.py --lossless` from the repository root to preserve transparency. Keep individual portraits at most 650 pixels on either side. Update `reference-data.js` variants when a depiction changes with reading progress.

`ref-snowman.webp` was supplied separately by the user; no original source URL was recorded. Preserve this Intermission-safe image. `ref-black-queen.webp` is her later depiction, not a substitute for the earlier portrait.
